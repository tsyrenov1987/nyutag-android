# Нютаг для Android

Мессенджер для бурятского сообщества: сервер `nyutag.chat` (протокол Matrix), вход по приглашению, интерфейс на бурятском и русском.

Клиент пишется с нуля на Kotlin, как и версия для iOS (`tsyrenov1987/nyutag-ios`). Сторонних библиотек нет:
только Android SDK, Jetpack Compose и стандартная библиотека Java (`javax.crypto`, `java.math.BigInteger`, `HttpsURLConnection`, SQLite из состава ОС).
К ядру клиент ходит обычным HTTPS через «двери» — несколько адресов с сертификатами Let's Encrypt.

## Состав

| Модуль | Что делает |
| --- | --- |
| `crypto` | Сквозное шифрование: своя реализация Olm и Megolm, Curve25519/Ed25519 на `BigInteger`, SSSS, бэкап ключей, SAS. Чистый Kotlin/JVM, тесты против эталона vodozemac (`src/test/resources/interop.json`, общий с iOS) |
| `core` | HTTP-слой клиент-серверного API, вход, `/sync`, хранилище, двери к ядру, комнаты (лента, список чатов, правки/реакции/ответы, каталог и сообщества, профиль, контакты, тишина, автоудаление, отложенные, Избранное, пересылка, стикеры, поиск, вид пуша), медиа (шифрование вложений AES-CTR, загрузка, скачивание, миниатюры, кэш на диске, волна голосовых), сквозное шифрование (Olm/Megolm в комнатах, запрос ключей у своих устройств, кросс-подпись, проверка по эмодзи, бэкап ключей, хранилище секретов под паролем), пуши (пушер у шлюза, текст уведомления с расшифровкой, правило звонка), модули Нютага (сервис `/_nyutag/v1`: приглашения, регистрация, вход по номеру, сброс пароля, поиск по номерам; обращения разработчика; бурятские буквы ө ү һ; Сагаалган и зурхай; свой QR-кодировщик для ссылки приглашения) — готово, 210 тестов |
| `app` | Приложение на Compose (в работе). Готово: выбор языка, вход, регистрация с кодом из письма, сброс пароля, список чатов, текстовый чат (отправка с повтором, показ ответов и реакций, «печатает», отметка прочтения), вкладки «Чаты», «Контакты», «Сообщества» и «Календарь», контакты из телефонной книжки и поиск людей с переходом в личный чат, «Пригласить друга» (код, QR, «Поделиться», отзыв своих кодов), сообщества (каталог с поиском, карточка сообщества, вступление и заявка в закрытое, выход, создание открытого и закрытого, группы внутри с созданием), календарь (дни до Сагаалгана, год по восточному календарю, зурхай на сегодня, Сагаалган по годам), меню «Я» под своим аватаром («Избранное», язык, выход, удаление аккаунта) с правкой профиля (имя, «о себе», тоонто, род, номер, восточный год), открытие старой истории ключом восстановления (карточка над чатами, после ввода хранилище перезапирается паролем); двери к ядру выбираются гонкой, сессия входа зашифрована ключом из Android Keystore |

Состояние Olm-сессий и аккаунта пишется в том же JSON, что у iOS-клиента, поэтому тестовые данные у двух клиентов общие.

## Сборка и тесты

Нужен JDK 21; на Маке подходит JBR из Android Studio:

```sh
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
./gradlew :crypto:test
./gradlew :app:assembleDebug
```

Ключ двери и адреса дверей в репозиторий не входят (`app/src/main/assets/nyutag-catalogue.txt`, `tools/test-env.local.sh` в `.gitignore`).
